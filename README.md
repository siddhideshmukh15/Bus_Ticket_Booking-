🚌 Bus Ticket Booking System

A simple Bus Ticket Booking System built using Python. This beginner-friendly project allows users to book tickets, view bookings, cancel tickets, and check available seats.

✨ Features

- 🎟️ Book bus tickets
- 👤 Store passenger name
- 📍 Store destination
- 💺 Check available seats
- 📋 View all bookings
- ❌ Cancel tickets
- 🚪 Exit the system

🛠️ Technologies Used

- Python
- Dictionaries
- Tuples
- Loops
- Conditional Statements
- User Input

🎯 Learning Purpose

This project helps practice basic Python concepts such as:

- Dictionaries
- Tuples
- "while" loops
- "for" loops
- "if-elif-else"
- "input()"
- "len()"
- "del"
